Flutter Basic Calculator App |              
:A simple and user-friendly calculator app built using Flutter. This app performs basic arithmetic operations like addition, subtraction, multiplication, and division with a clean and responsive user interface.

### ✨ Features
- Perform basic operations: Add, Subtract, Multiply, Divide  
- Clear button to reset input  
- Responsive layout for both portrait and landscape orientations  
- Built using custom buttons and display widgets  
- Smooth and fast performance on all devices  

### 🛠 Tech Stack
- Flutter (UI framework)  
- Dart (Programming Language)
